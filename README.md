# Plume — build copy

Plume is the desktop app of [Orneos](https://orneos.eu): mail, calendar, contacts, notes, tasks, passwords and the
Ornis assistant, for Windows, macOS and Linux.

This repository only builds it. Its content is replaced at each build by a copy of the files the build needs, taken
from Orneos's private repository: edits made here are lost. Builds go to draft releases; Orneos signs and publishes
them on its own server. Download Plume from https://orneos.eu.
